- no change for projects using the plugin: everything in this release is for work on the plugin itself
- `scripts/test-foundation.sh changed` runs only the tests that name a file the branch touched, plus the tests marked `# changed: sweep` (they reach skills, workflows or a whole tree without naming a file) when anything under `skills/`, `conventions/`, `templates/`, `workflows/` or `commands/` moves, and the whole suite when a test helper or fixture moves; `changed --list` prints the choice without running it. `tests/foundation/lib/changed-sweep.test.bats` keeps the marks honest
