- **Behavior change:** new PreToolUse hook `hooks/long-sleep-guard` on every Bash call refuses a foreground `sleep` longer than 60 s, exit 2 with the reason on stderr; such a sleep waits its whole length after the job it waits for has finished, and in Claude Code it holds back that job's completion notification until it ends, so a session that finished its tests in four minutes looked hung for twenty; the refusal names the way out: `scripts/long-run.sh wait`, which returns when the job exits, or `run_in_background` and ending the turn
- only a `sleep` in command position counts (start of a line, after `;` `&` `|` `(` `` ` `` `$(` or `do` / `then` / `else`); a `sleep` inside an argument — a commit message, an `echo`, a `grep` pattern — passes, as do a background call, `long-run.sh wait`, every tool but Bash, and any input the hook cannot read; units `s` `m` `h` `d` are read and several arguments add up
- `SPINE_SLEEP_LIMIT` in the environment, in seconds, raises the limit; it is not a project config key
- the hook fires in every session where the plugin is enabled, inside a task or not, and in Codex too, which reads the same `hooks/hooks.json`; a call without the word `sleep` returns before `python3` starts
- `conventions/agent-tooling.md` → Long-running commands now says never to wait on a running job with a bare `sleep`; the README names the hook and the variable
- a project that carried its own copy of such a hook can drop it, or every refusal arrives twice
- `scripts/docs-route.sh` progress no longer reads a `Tasks/` that is its own repository as tasks: hidden and underscored status folders are skipped, and a task is only a folder named `NNN` or `NNN-slug`; an existing progress file without a marker pair is refused and left untouched, exit 1, instead of getting the table appended to its end
- no platform change: none of the six vendored files moved since 2.34.0 (`scripts/lint-manifest.sh`, `scripts/lint-i18n.sh`, `scripts/lint-locales.sh`, `scripts/lint-core-refs.sh`, `scripts/test-foundation.sh`, `conventions/i18n.md`), so no platform has to re-vendor
