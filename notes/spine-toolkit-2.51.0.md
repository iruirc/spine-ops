- **Evidence no longer enters history raw.** New `scripts/evidence.sh`:
  - `raw <evidence dir>` makes `raw/` with a `.gitignore` of `*` and prints its path;
  - `keep <log> <evidence dir> [--name <name>] [--match <regex>]…` copies the log into `raw/` and writes a scrubbed excerpt beside it: a header naming the raw copy, the lines any `--match` regex finds, then `# tail` and the last 20 lines. The whole log is scrubbed before lines are picked, so a private key cut by the tail leaks no body line;
  - `keep-image <evidence dir>/raw/<image> <evidence dir>` moves a screenshot the agent looked at into history and lists its sha1 in `kept.txt`;
  - `check <task dir>` prints `evidence path=<path> reason=<unmarked|secret|unlisted|changed|other>` for every file of `phase-evidence/` and `validation-evidence/` (step folders included) that may not be committed. Exit 0 clean, 1 findings, 2 a usage or configuration error.
- One set of redaction rules: `key=value`, `key: value`, JSON, single-quoted and `=>` pairs for token, secret, password, api key, auth, credential, private key, session and cookie keys; `Authorization` with any scheme (only a known scheme word stays visible); `X-Api-Key`, `Cookie`, `Set-Cookie`; credentials and secret query parameters in URLs; JWTs; private key blocks; known key prefixes (`AKIA`, `ghp_`, `github_pat_`, `sk-`, `xox?-`, `AIza`). A project adds its own patterns in a `## Redact` block of `SPINE.md`, one ``- `<regex>` `` per line; any other line, or a pattern that does not compile or matches the empty string, stops `evidence.sh` with exit 2 naming the line. Not DLP: unknown token shapes pass.
- `stage-leftovers.sh foreign` asks `evidence.sh check` before the Done commit: a raw copy, an excerpt with a secret, an unapproved or changed screenshot, and, inside git, any file under `raw/` that git does not ignore are foreign and go through the usual exclude / remove / commit question. Paths are compared in NFC, and a `check` that fails or names nothing on exit 1 stops the commit with exit 2. `experiment/` stays lawful whole; the post-stage `diff` is unchanged.
- The texts agents act on — `conventions/agent-tooling.md`, `conventions/stage-dispatch.md`, the workflow brief and every `profile-*.js`, `phase-verification`, `task-documents`, the `workflow-*` skills and the orchestrator — cite a log by its excerpt, never by its raw copy, give `--match` as a regex, and save a screenshot only into the folder `evidence.sh raw` prints. The `ran:` line and the `## Regression set` table keep their form; their log paths now name excerpts. `docs/configuration.md` documents `## Redact`.
- An `evidence.sh` exit 2 that names `## Redact`, the project config or the task folder is a configuration error, not an older core.
- **Stage leftovers remember restores.** A file restored after a stage that comes back with the same content is marked as rewritten by the environment, and the check recommends leaving it rather than restoring it again; what the user chose to leave is listed at Done while it still differs from HEAD. Each path is restored alone and literally, and a failed restore says what it means.
- **Open questions are not lost.** An open question sits under a heading beginning `Open Questions`, one list item each (`task-documents`); `open-questions.sh` reports a question outside the sections it reads on stderr and names a subheading inside one, and the gate shows the questions the script could not read and repeats its table after the dialog.
- A launch request exempts the choice of which review findings to fix from the typed confirmation, never a decision on how to fix one.
- Compatibility: a platform older than spine-platform-swift 1.42.0 / spine-platform-kotlin 1.30.0 still copies raw logs, so every Done asks about them as foreign files until the platform is updated. A task started before this release that will be carried later should commit its cited phase logs rather than exclude them, or the `ran:` and `Log` paths it cites will be missing in a fresh clone.
