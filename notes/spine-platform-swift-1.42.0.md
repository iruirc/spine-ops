- `swift-validator` keeps every log `Validation.md` names with spine-toolkit's `evidence.sh keep` into `<task_path>/validation-evidence/<timestamp>/`: the raw log goes to a `raw/` git never sees, and `Validation.md` cites and quotes only the scrubbed excerpt beside it. Its `--match` regexes keep XCTest's `Executed N tests` and `Test Case '…' failed`, Swift Testing's `Test run with N tests` summary and its `✘` / `↳` issue lines, `error:`, `** BUILD FAILED **` and `** TEST FAILED **`; none is anchored, since a line may begin with a tab or a zero-width space
- a device, simulator or crash log the run quotes is kept the same way, under a slug `--name`
- a screenshot is saved into the folder `evidence.sh raw` prints and enters history only through `evidence.sh keep-image`, after the validator looked at it and saw no credentials, tokens, keys or personal data; `## UI Smoke` says `viewed: no secrets on screen`, or names an unkept screenshot by its `raw/` path
- an `evidence.sh` exit 2 naming `## Redact`, the project config or the task folder fails the step with that message; it is not an older core
- works with spine-toolkit 2.51.0 and later, the release that ships `evidence.sh`
