- the prelude shared by the eight profile scripts now has one source, `workflow-src/prelude.js`; the copies in `workflows/profile-*.js` are generated from it and committed, so a change to the shared rules is one edit and one sync instead of eight identical edits; the plugin still installs from git as is, with no build step
- new `scripts/sync-workflow-prelude.sh [--check]` copies the source into every `workflows/profile-*.js` between the `// ── prelude ─` and `// ── end prelude ─` lines; without a flag it rewrites only the scripts that differ and prints `synced N of M`; `--check` writes nothing; exit 0 in sync, 1 `--check` found a difference, 2 usage or structure error (a missing source, a script with other than one opening and one closing marker, or the markers reversed), and on 2 nothing is written because every script is checked before the first one is touched
- `scripts/lint-workflows.sh` compares every copy with `workflow-src/prelude.js` instead of with the alphabetically first script, and names the fix: `workflows/<file>: prelude differs from workflow-src/prelude.js — run scripts/sync-workflow-prelude.sh`; a missing source is a violation, and the `Task id: … — profile …, stage ….` line that `scripts/agent-metrics.sh` recovers from a transcript is checked in the source too
- `workflow-src/` sits outside `workflows/`, so the source is never registered as a workflow; `conventions/stage-dispatch.md` says the prelude is edited only there
- no profile behaves differently: in each script only the three comment lines after the opening marker changed
- no platform change: none of the six vendored files moved since 2.33.0 (`scripts/lint-manifest.sh`, `scripts/lint-i18n.sh`, `scripts/lint-locales.sh`, `scripts/lint-core-refs.sh`, `scripts/test-foundation.sh`, `conventions/i18n.md`), so no platform has to re-vendor
