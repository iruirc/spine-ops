- `Walkthrough.md`: every commit reference carries its repository as one token, `repo@sha` or `repo@a..b`, the repository named by its checkout folder (`task-walkthrough`, `task-documents` for `Done.md`). `scripts/lint-walkthrough.sh` reads the prefix: a reference without one is a `style` line, which does not make the file stale; a reference to a repository that does not hold the sha is a `repository` finding, which does. An old perimeter name, an address or a version is not read as a commit
- `scripts/task-ranges.sh`: `names` lists a task's repositories by folder, and `owners` says which of them holds a sha
- a BUG replay carried by a re-run passes on the statement it is carried from
- the Codex install block in the docs has no comments, so it pastes into a shell that does not take them
- development of the toolkit itself: `scripts/test-foundation.sh touched` with no files runs the tests that name what the next commit holds — the files that differ from HEAD and the untracked ones — with no sweeps and no branch base. A changed test file runs itself, a changed helper runs only the tests that load it (through other helpers too), a changed fixture runs all of `lib/`, and a change under `skills/<name>/` runs the tests that name that skill. With files, `touched` behaves as before, so `release.sh` is unaffected
- a sweep's mark names the directories it walks, `# changed: sweep skills workflows`, and `changed` runs it only for a change in one of them. `tests/foundation/helpers/sweep-lint.bash` derives those directories and `changed-sweep.test.bats` holds every mark to it; mixed test files are split so their walking tests sit in a small `*-sweep.test.bats`. A one-paragraph skill edit selects 40 files instead of 49, 568 tests instead of 1169
- the moved-config-block checks (`config-format`, the profile check in `settings-resolver-sweep`) print the matching line and how to name the section instead
- platforms: `scripts/test-foundation.sh` moved; spine-platform-kotlin 1.25.0 and spine-platform-swift 1.37.0 carry its new hash
