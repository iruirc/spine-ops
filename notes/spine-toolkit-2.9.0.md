- a stage agent searches for a file only under known roots: the project root, every checkout `## Paths` lists under `External packages`, every folder it lists under the new `Roots` key, the core root and the base directory of a skill it loaded. Never from `/` or `~`; a file under none of them is reported missing instead of searched for further (`conventions/agent-tooling.md` → Finding files)
- `## Paths` takes `- Roots: <path>`, repeatable, absolute or relative to the project root, for folders outside the build the project may read; a `Roots` entry that names no folder is skipped with a stderr line
- `scripts/resolve-settings.sh json` prints `roots`, absolute and without nested duplicates; the orchestrator passes it in the contract, every profile brief lists it in a `Search roots:` line, and the epic forwards it to its steps. An older contract without `roots` still runs, with the project root and the core root only
- nothing the platforms vendor moved, so none of them has to re-vendor
