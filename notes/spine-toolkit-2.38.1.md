- no change for projects using the plugin: everything in this release is for work on the plugin itself
- a green `scripts/test-foundation.sh all` records the tree it ran on in `spine-verified-trees` under the git common dir: the working tree as `git add -A` would stage it, hashed through a scratch index, the real index untouched. It is recorded only when bats passed and the tree did not change during the run; the file keeps the last 20 trees. `unit`, `changed` and a direct `bats <file>` record nothing
- new mode `scripts/test-foundation.sh touched <file>...` runs the tests under `tests/foundation/lib/` that name any of the files, without the fixture, helper and sweep rules of `changed`; when no test names them it says so and exits 0. `spine-ops` release runs it on the files a release rewrites when the tree being released passed a full run
- platforms: `scripts/test-foundation.sh` moved, so the adapted copies in spine-platform-swift and spine-platform-kotlin are re-pinned to this release's runner
