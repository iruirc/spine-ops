- `test-frameworks` names each framework's result line in a `### Result line` subsection: XCTest's `Executed N tests, with M failures …` (the last `Executed` line of the run), Swift Testing's `✔ Test run with N tests in K suites passed …` (the count is tests, not suites; the line is found by `Test run with`, as a zero-width space may precede the mark), Quick+Nimble by XCTest's rule. In a mixed `swift test`, `Executed 0 tests` is not a result line; when XCTest counts tests both lines are, and N is their sum
- `swift-validator` reads the `ran:` line in the form spine-toolkit 2.49.0 writes, `tests <N> result "<result line>"`, and in the older `Executed <N>` form; the `Tests` count of a row it reruns is the sum of the run's result lines, never every `Executed` line
- works with spine-toolkit 2.46.0 and later; the new `ran:` form comes from 2.49.0
